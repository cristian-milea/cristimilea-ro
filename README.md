# cristimilea.ro

Personal portfolio site for Cristian Milea. Built with [Astro](https://astro.build),
based on the [Astro-portfolio](https://github.com/Gothsec/Astro-portfolio) template
(MIT licensed). Deployed on Cloudflare Pages, auto-deployed on every push to `main`.

## Development

```bash
pnpm install
pnpm dev
```
